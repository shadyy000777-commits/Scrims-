# Scrims Bot (Rebound + T3)

Railway Variables:
- `DISCORD_TOKEN`, `CLIENT_ID` (this bot's own application)
- `DATABASE_URL` (Postgres)
- `ALLOWED_USER_IDS` — comma-separated Discord user IDs allowed to use the bot
- optional: `OWNER_ID`, `PREFIX` (default `!`), AI chat keys

Start command: `npm start`
